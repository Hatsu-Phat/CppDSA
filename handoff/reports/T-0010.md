3. `src/grader/src/runner.ts`: Tính time limit theo CPU time (`rusage.user_time + rusage.sys_time`), wall deadline `TL * GRADER_WALL_FACTOR + 1000ms` bắt `sleep`, `timeMs` trả về là CPU time.
4. `src/grader/src/config.ts`: Quản lý các biến môi trường cấu hình P8 (PCH, timeout, limits, cgroup logging).
5. `src/grader/src/queue.ts`: Structured JSON logging (pino format) chứa `jobId`, `submissionId`, `queuedAt`, `queueMs`, `compileMs`, `runMs`, `totalMs`, `verdict`, `score` mà không lộ mã nguồn/secret/test ẩn; endpoint lưu `recentMetrics`.
6. `src/grader/src/app.ts`: Endpoint `/jobs/:submissionId/metrics` phục vụ đo latency breakdown trong load test.
7. `src/grader/tests/hardening.test.ts`: Bổ sung đầy đủ 7 test kiểm chứng: compile timeout ra CE thân thiện, sanitize compile error redacts token, compiler blocks sensitive path include, PCH directory read-only cho non-root, wall deadline catches sleep (5s/TL 200ms -> TLE), CPU-time TLE (rusage > TL -> TLE), CPU-time AC (CPU 800ms / TL 1000ms -> AC và `timeMs` đúng 800ms).

10. `src/api/src/routes/submissions.ts`: Rate limit 6 lần nộp/phút/sinh viên theo user id hoặc IP.
11. `src/api/src/routes/internal.ts`: Rate limit 120 req/min và xác thực `X-Grader-Secret` bằng constant-time compare.
12. `src/api/tests/hardening.test.ts`: Test rate limit toàn cục IP trả 429 tiếng Việt, test fastify logger stream redact secret/password/source code, test internal callback auth.
13. `tests/grading/cases.mjs`: Bổ sung 8 ca kiểm thử grading mới: TC-46 đến TC-49 (PCH regression tests a, b, c, d), TC-50 (CPU loop under TL AC), TC-51 (sleep wall deadline TLE), TC-52 (busy loop CPU > TL TLE), TC-53 (CPU 800ms / TL 1000ms AC).
