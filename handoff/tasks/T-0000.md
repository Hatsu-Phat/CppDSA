# T-0000 — Kiểm chứng chuỗi Claude → Antigravity (không code)

- Phase: P0 · Vòng: 2/3 · Ngày: 2026-10-31
- Mục tiêu (một câu): xác nhận agy chạy headless đúng model, nạp được file quy tắc và ghi được báo cáo.
- Allowed files (được tạo/sửa): `handoff/reports/T-0000.md` (duy nhất).
- Context files (chỉ đọc, tối thiểu): `AGENTS.md`, `GEMINI.md`.
- Tiêu chí nghiệm thu (đo được):
  1. Tồn tại `handoff/reports/T-0000.md` theo `handoff/REPORT_TEMPLATE.md`.
  2. Báo cáo nêu tên model đang chạy (nguyên văn, không đoán; không biết thì ghi "không xác định được").
  3. Báo cáo liệt kê các file quy tắc/ngữ cảnh thực sự được nạp vào phiên (AGENTS.md, GEMINI.md, ~/.gemini/GEMINI.md…), mỗi file ghi "có/không/không xác định được" và trích dòng đầu tiên của file đó làm bằng chứng.
  4. Báo cáo ghi kết quả lệnh `git status --short` và `git rev-parse --abbrev-ref HEAD` (output nguyên văn).
  5. Không có file nào khác bị tạo/sửa.
- Lệnh kiểm chứng (phải chạy và dán 20 dòng cuối):
  - `git status --short`
  - `git rev-parse --abbrev-ref HEAD`
- Tự sửa: không áp dụng (không có code).
- Cấm: tạo/sửa file ngoài Allowed files; đụng `data/`, `.git/`, `.claude/`.
- Ràng buộc headless: lệnh shell được phép DUY NHẤT là 2 lệnh git ở trên. Không dùng `Get-Content`, `cat`, `type`, `Select-String`… (bị từ chối và hủy phiên). Đọc file trong project bằng công cụ đọc file. File ngoài project (vd `~/.gemini/GEMINI.md`) nếu không đọc được bằng công cụ file thì ghi "không xác định được" kèm lý do, hoặc trích nội dung nếu nó đã có sẵn trong ngữ cảnh phiên.
- Phản hồi vòng trước (nếu có): vòng 1 (2026-11-01) bị hủy do dùng `Get-Content` đọc `~/.gemini/GEMINI.md`.
