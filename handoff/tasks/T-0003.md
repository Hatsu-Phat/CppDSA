- Mục tiêu (một câu): dựng spike grader (Node.js + g++ C++17) chạy trong 1 Docker container KHÔNG privileged, biên dịch/chạy code không tin cậy với giới hạn TL/ML/tiến trình/file/mạng, phân loại verdict đúng và chặn được các kịch bản tấn công; đo và báo cáo, làm đầu vào cho việc thử trên Render ở task sau.

Vì vậy cơ chế cách ly phải hoạt động trong `docker run` mặc định (không cờ bảo mật bổ sung). Gợi ý (không bắt buộc): launcher C nhỏ chạy với root trong container → tạo thư mục tạm riêng → `setrlimit` (CPU, AS/DATA, NPROC, FSIZE, NOFILE, CORE=0) → `setgid/setuid` sang user `sandbox` không đặc quyền → `PR_SET_NO_NEW_PRIVS` + seccomp filter (libseccomp) chặn `socket`/`connect`/… → `execve`; tiến trình Node cha đo wall-time, kill cả process group khi quá hạn, cắt output ở giới hạn, so sánh output bên ngoài sandbox. Được dùng giải pháp khác nếu đạt tiêu chí trong `docker run` mặc định; ghi rõ lý do lựa chọn.
