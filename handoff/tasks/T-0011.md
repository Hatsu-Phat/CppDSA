# T-0011 — Sửa lỗi API trước deploy (P9 chuẩn bị)

- Phase: P9 (chuẩn bị) · Vòng: 1/3 · Ngày: 2026-11-01 · Branch: `task/T-0011` (Claude tạo sẵn; không commit, không đổi branch)
- Mục tiêu (một câu): sửa 4 lỗi API Claude tìm thấy khi kiểm thử trước deploy (rate limit sau proxy, CSV formula injection, UUID sai → 500, thiếu kiểm biên TL/ML) và các mục gia cố cấu hình production nhỏ, kèm test.
- Context files (chỉ đọc, tối thiểu): `TEST_REPORT.md` mục "Kiểm thử API trước deploy"; `src/api/src/app.ts`, `src/api/src/config.ts`, `src/api/src/routes/{auth,submissions,assignments,grades,classrooms,test-cases}.ts`; `src/grader/src/{app,queue}.ts`; `src/web/app/student/assignments/[id]/page.tsx` (poll 2 s); `src/api/tests/*`.
- Quyết định (Claude chốt):
  1. **Proxy/IP:** thêm env `TRUST_PROXY` (mặc định `false`; số nguyên = số hop proxy tin cậy, truyền vào Fastify `trustProxy`). Production sẽ đặt `TRUST_PROXY=2` (Vercel → Render) — giá trị đúng xác minh ở P9.
  2. **Khóa rate limit KHÔNG phụ thuộc IP duy nhất:**
     - Đăng nhập: khóa = email đã chuẩn hóa (lowercase, trim) → `LOGIN_RATE_LIMIT_MAX` (mặc định 10/phút/email); thêm giới hạn lỏng theo IP `LOGIN_IP_RATE_LIMIT_MAX` (mặc định 100/phút/IP) để phòng dò nhiều email. 50 SV cùng một IP NAT đăng nhập trong 1 phút phải được.
     - Global `/api/*`: khóa = `user.id` nếu đã đăng nhập, ngược lại IP; mặc định `GLOBAL_RATE_LIMIT_MAX=300`/phút/khóa. Một SV poll 2 s/lần (30 req/phút) không bao giờ chạm giới hạn; 50 SV sau cùng một IP không ảnh hưởng nhau.
     - Nộp bài giữ nguyên 6/phút/sinh viên.
  3. **CSV formula injection:** trong `/classrooms/:id/grades/csv` (và mọi xuất CSV khác nếu có), ô bắt đầu bằng `=`, `+`, `-`, `@`, tab, CR → thêm tiền tố `'`; vẫn escape dấu phẩy/ngoặc kép đúng RFC 4180.
  4. **UUID:** mọi tham số đường dẫn `:id`, `:studentId` không phải UUID hợp lệ → 400 JSON tiếng Việt (vd `{ error: 'BAD_REQUEST', message: 'Mã không hợp lệ' }`) TRƯỚC khi truy vấn DB. Error handler chung: lỗi 5xx KHÔNG trả `code`/`message` gốc của PostgreSQL ra client (chỉ thông báo chung; log server vẫn giữ chi tiết).
  5. **Biên bài tập (tạo và sửa):** `timeLimitMs` nguyên trong [100, 10000]; `memoryLimitMb` nguyên trong [16, 512]; ngoài khoảng → 400. Không đổi schema response.
  6. **Production guard:** khi `NODE_ENV=production`, API thoát với thông báo rõ nếu thiếu `GRADER_SECRET`, thiếu `COOKIE_SECRET` hoặc `COOKIE_SECRET` = giá trị mặc định dev, hoặc `DATABASE_URL` trỏ `localhost`. `src/api/Dockerfile` đặt `ENV NODE_ENV=production` (compose local ghi đè `NODE_ENV=development` nếu cần để test cũ chạy).
  7. **Grader:** `GET /jobs/:id/metrics` yêu cầu header `X-Grader-Secret` như `POST /jobs`; `recentMetrics` giữ tối đa 1000 mục (xóa cũ nhất). Cập nhật `tests/load/load-test.mjs` gửi header (secret lấy từ env `GRADER_SECRET`, mặc định `dev-grader-secret`).
  8. Tài liệu: `docs/DEV_SETUP.md` bảng biến môi trường cập nhật đúng giá trị chốt P8 (`GRADER_CONCURRENCY=1`, `GRADER_MEMORY_BUDGET_MB=400`, `COMPILE_TIMEOUT_MS=15000`) và thêm `TRUST_PROXY`, `LOGIN_IP_RATE_LIMIT_MAX`, `COOKIE_SECRET`, `NODE_ENV`. `.env.example` thêm các biến mới (giá trị giả, không secret thật).
