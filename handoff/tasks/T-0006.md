  - Template mode: ghép theo `// STUDENT_BEGIN <tên>` / `// STUDENT_END`; thiếu/thừa/sai tên vùng → từ chối job (400, không chấm). Không bao giờ nhận file đầy đủ.
  - Free mode: giảng viên cung cấp `harness` (adapter) dùng định danh `CPPDSA_ENTRY`; grader tự sinh phần đầu: function → `#define CPPDSA_ENTRY <name>`; method → hàm bao `template<class... A> decltype(auto) CPPDSA_ENTRY(A&&... a){ static <Class> o; return o.<method>(std::forward<A>(a)...); }`. `name`/`className` phải khớp `^[A-Za-z_][A-Za-z0-9_]{0,63}$` và không phải từ khóa C++; sai → 400. Sai tên/chữ ký → CE.
  - Kết quả: `{ submissionId, status:"DONE"|"SYSTEM_ERROR", verdict, score (đạt/tổng), tests:[{ index, verdict, timeMs, memoryKb }], compileMessage? }`. KHÔNG chứa input/expected/actual/đường dẫn. `compileMessage` ≤ 2000 ký tự, thay đường dẫn tạm bằng tên file logic (`solution.cpp`, `template.cpp`), xóa mọi chuỗi giống secret/env.
  - Verdict tổng: CE nếu biên dịch lỗi; ngược lại AC nếu mọi test AC, nếu không là verdict của test lỗi đầu tiên. Điểm = số test AC / tổng.
