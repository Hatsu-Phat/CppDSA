  - Stack giữ Fastify + `pg` + `node-pg-migrate`. Gói được phép thêm: `@fastify/cookie`, `@fastify/rate-limit`, `bcryptjs` (thuần JS, tránh build native). Không thêm gói khác; cần gói khác → ghi BLOCKED và lý do.

  - Phiên: bảng `sessions` (token ngẫu nhiên 32 byte, chỉ lưu hash SHA-256, hạn 12 giờ), cookie `sid` httpOnly, `SameSite=Lax`, `Secure` khi `NODE_ENV=production`. Mật khẩu bcrypt cost ≥ 10. Cờ `must_change_password`: mọi endpoint trừ `POST /auth/change-password`, `POST /auth/logout`, `GET /auth/me` trả 403 `PASSWORD_CHANGE_REQUIRED`.
  - Giảng viên đầu tiên: script `npm run seed:lecturer -w @cppdsa/api` đọc email/mật khẩu từ env (`SEED_LECTURER_EMAIL`, `SEED_LECTURER_PASSWORD`); không có đăng ký công khai.
  - Endpoint tối thiểu (tiền tố `/api`): auth (login, logout, me, change-password); lớp (CRUD của giảng viên sở hữu; import CSV sinh viên với lỗi từng dòng — AC-US-01-2; reset mật khẩu sinh viên — US-08); bài tập (CRUD; mode template/free; kiểm tra marker template khi lưu — AC-US-02-2; free mode lưu harness + mô tả giao diện; TL mặc định 1000 ms, ML 256 MB; deadline); test (ví dụ công khai nằm trong đề; hidden tests CRUD chỉ giảng viên); submission (sinh viên nộp: template gửi `regions` — backend ghép bằng `stitchTemplate`, free gửi `studentSource` + entry; trạng thái `PENDING/RUNNING/COMPLETED/SYSTEM_ERROR`; lịch sử của chính mình; chi tiết kết quả theo hợp đồng không có input/expected/actual); giảng viên xem mọi submission lớp mình (lọc theo bài, thời gian, trạng thái, khoảng điểm — AC-US-05-1) + mã nguồn + compileMessage; bảng điểm CSV (điểm cao nhất trước deadline, cột Late — US-06); `POST /api/system/warmup` (giảng viên; gọi `GET /health` grader và `SELECT 1`, trả trạng thái từng thành phần — US-07); `POST /api/internal/grader-callback` (header `X-Grader-Secret`, so sánh thời gian hằng; env trống → 503).
  - Hàng đợi/phục hồi: nộp → ghi `PENDING` → gửi job HTTP tới `GRADER_URL` với `X-Grader-Secret`; grader lỗi mạng → vẫn `PENDING`. Mỗi request tới API gọi (không chặn response) bước phục hồi dùng `decideRecovery` của `src/shared` (không timer nền). Callback ghi kết quả + `submission_test_results` trong 1 transaction; callback lặp lại cho cùng submission là idempotent.
  - Điểm: score = đạt/tổng; điểm chính thức = max score các submission `COMPLETED` có `submitted_at <= deadline`; submission sau deadline có `is_late = true`, vẫn chấm, không đổi điểm chính thức (US-16, US-17).
  - Giới hạn kích thước (cấu hình env, có mặc định): mã sinh viên ≤ 64 KB, template/harness ≤ 64 KB, mỗi input/expected ≤ 1 MB, ≤ 50 hidden tests/bài, CSV ≤ 500 dòng → vượt 413/400 có mã lỗi.
  - Rate limit: đăng nhập 10 lần/phút/IP; submit 6 lần/phút/người dùng → 429.
  - Credential (`DATABASE_URL`, `GRADER_SECRET`, `SESSION_*`) chỉ đọc từ env của API; không in ra log; không có trong `src/web`/`src/shared`. `.env.example` chỉ chứa giá trị giả.
