- Môi trường: host Windows, KHÔNG có `node`/`npm`/`g++`; Docker Desktop đang chạy. Mọi lệnh npm chạy trong container `node:22-bookworm` mount thư mục project. Không chạy lệnh dò môi trường. Lệnh shell được phép: các lệnh kiểm chứng dưới đây và `git status/diff/rev-parse`; đọc/sửa file bằng công cụ file. Khi gọi lệnh docker, đặt `WaitMsBeforeAsync` = 600000 để chờ đồng bộ (lệnh có thể mất vài phút); không chạy nền.
- Lệnh kiểm chứng (chạy từ thư mục gốc project trong PowerShell; dán 20 dòng cuối mỗi lệnh):
  1. `docker run --rm -v "${PWD}:/w" -w /w node:22-bookworm sh -c "npm ci && npm run lint && npm run format:check && npm run build && npm test"`
  2. `docker compose up -d --build`
  3. `docker compose ps`
  4. `docker run --rm --network host curlimages/curl:8.10.1 -sf http://127.0.0.1:4000/health` (và tương tự 4100, 3000) — nếu `--network host` không hoạt động trên Docker Desktop, dùng `docker compose exec api node -e "fetch('http://localhost:4000/health').then(r=>r.text()).then(console.log)"` và ghi rõ lựa chọn.
  5. `docker compose down -v`
