# T-0014 — Đề bài PDF lưu trên Google Drive (thay mô tả + ví dụ công khai)

- Mục tiêu (một câu): giảng viên tải lên file PDF đề bài khi tạo/sửa bài tập (thay ô mô tả và ví dụ công khai), file lưu trong Google Drive của tài khoản chủ hệ thống, sinh viên xem PDF ngay trong trang làm bài qua API (file không công khai).
- Context files: `src/api/src/routes/assignments.ts`, `src/api/src/app.ts`, `src/api/src/config.ts`, `src/api/migrations/*`, `src/web/components/AssignmentForm.tsx`, `src/web/app/student/assignments/[id]/page.tsx`, `docs/API.md`, `docs/openapi.yaml`.
- Quyết định (Claude chốt):
  1. Migration mới `src/api/migrations/0003_assignment_statement_pdf.cjs`: thêm vào `assignments` các cột NULL được `statement_storage varchar(16)`, `statement_file_id text`, `statement_file_name varchar(255)`, `statement_file_size integer`; có `down`. KHÔNG sửa migration cũ.
  2. Lớp lưu trữ `src/api/src/services/statement-storage.ts` với 2 driver: `gdrive` (khi có đủ `GDRIVE_CLIENT_ID`, `GDRIVE_CLIENT_SECRET`, `GDRIVE_REFRESH_TOKEN`; tùy chọn `GDRIVE_FOLDER_ID`) và `local` (thư mục `STATEMENT_LOCAL_DIR`, chỉ dùng dev/test/E2E). Chọn bằng `STATEMENT_STORAGE=gdrive|local` (mặc định: `gdrive` nếu đủ biến, ngược lại `local` khi `NODE_ENV!=production`, còn production thiếu biến → upload trả 503 "Chưa cấu hình lưu trữ đề bài PDF").
  3. Driver Google Drive dùng REST qua `fetch` (KHÔNG thêm gói): lấy access token bằng refresh token (`POST https://oauth2.googleapis.com/token`, cache tới gần hết hạn), tải lên `POST https://www.googleapis.com/upload/drive/v3/files?uploadType=multipart` (metadata `name`, `mimeType: application/pdf`, `parents: [GDRIVE_FOLDER_ID]` nếu có), tải xuống `GET https://www.googleapis.com/drive/v3/files/{id}?alt=media`, xóa `DELETE .../files/{id}`. Scope dự kiến `drive.file`. Không đặt quyền chia sẻ công khai. Log không chứa token.
  4. API: `PUT /api/assignments/:id/statement` (giảng viên chủ lớp) nhận body thô `Content-Type: application/pdf` (thêm content-type parser dạng Buffer, giới hạn 10 MB qua `MAX_STATEMENT_PDF_BYTES`), tên file qua header `X-File-Name` (URL-encoded, cắt 255 ký tự); kiểm 5 byte đầu `%PDF-` → sai 400; thay file cũ thì xóa file cũ trên storage sau khi lưu file mới thành công. `DELETE /api/assignments/:id/statement` xóa. `GET /api/assignments/:id/statement` (giảng viên chủ lớp hoặc sinh viên đã ghi danh) stream PDF với `Content-Type: application/pdf`, `Content-Disposition: inline; filename*=UTF-8''...`, `Cache-Control: private, max-age=300`; người ngoài → 403/404. `GET /api/assignments/:id` trả thêm `statement: { name, size } | null` (không lộ file id).
  5. Web: form tạo/sửa bài có khu "Đề bài (PDF)" kéo-thả/chọn file, hiện tên + dung lượng, nút xóa; ô mô tả thành tùy chọn ("Ghi chú thêm (không bắt buộc)"); bỏ phần nhập ví dụ công khai trong form (test `is_sample` cũ vẫn hiển thị nếu có). Trang làm bài sinh viên: nếu có PDF → khung xem PDF (`<iframe>`/`<object>` tới `/api/assignments/:id/statement`, cao ≥ 70vh, có nút "Mở tab mới"/"Tải về"); không có PDF → hiện mô tả như cũ.
